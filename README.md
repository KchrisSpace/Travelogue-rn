# Travelogue-rn 📱✈️

一个使用 React Native 和 Expo 开发的旅行记录应用，帮助用户记录和分享他们的旅行经历。

## 功能特点 ✨

- 📝 创建和编辑旅行日记
- 📸 上传和管理旅行照片
- 🎥 视频播放和分享
- 🗺️ 记录旅行路线和地点
- 📊 统计旅行数据
- 👥 社交分享功能
- 🎨 精美的 UI 设计
- 🔍 图片查看器支持缩放
- 📱 支持手势操作

## 环境要求 📋

- Node.js >= 18
- npm >= 9
- Expo CLI
- iOS 模拟器 (macOS) 或 Android 模拟器
- Xcode (iOS 开发)
- Android Studio (Android 开发)

## 开始使用 🚀

1. 克隆项目

   ```bash
   git clone [项目地址]
   cd Travelogue-rn
   ```

2. 安装依赖

   ```bash
   npm install
   ```

3. 启动应用

   ```bash
   npx expo start
   ```

在输出中，你可以选择以下方式运行应用：

- [开发构建](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android 模拟器](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS 模拟器](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go)
